## What's new

- **More than one vehicle.** Add your car, bike or anything else in Settings → Vehicles. Each one keeps its own fill-ups, statistics, trend charts and tank size. Switch between them with the chip under the FuelPulse title.
- **Your data moves over as it is.** Every existing fill-up goes into a vehicle called "My vehicle", which keeps your tank size. Rename it in Settings.
- **In-app updates.** FuelPulse checks GitHub once a day and shows a card when a new version is out. It downloads the build for your phone's processor, and installs it only if it is FuelPulse, signed with the same key and newer than what you have. Turn the daily check off in Settings → About.
- **Clearer charts.** The average now sits next to each chart's title instead of on top of the line, and month labels show the year when a chart spans more than one.
- **Fewer wrong readings.** KM mode refuses a negative distance.

## Before you update

- This update installs over v1.2.0 and v1.3.0 with your data intact. If you are on v1.0.0 or v1.1.0, export a backup in Settings, uninstall, install this version, then import the backup: those builds were signed with a different key.
- Download `app-arm64-v8a-release.apk`. It runs on almost every phone. From this version on, the app picks the right file for you.
- Backup files made by this version need v2.0.0 or later to restore with their vehicles.
