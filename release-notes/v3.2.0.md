## What's new

- **Km-only schedules ask for notifications.** A service scheduled only by km now shows the Android permission prompt when you save it, so its reminder can appear. Before, only a schedule with a date asked.
- **Rescheduled services remind again.** After a km reminder fired, moving the service to a new due km left it silent. Each new due km now gets its own reminder.
- **Deleted services stop reminding.** Delete all data and deleting a vehicle now cancel their date reminders straight away, instead of at the next app start.
- **In-app updates ride out GitHub hiccups.** When GitHub's download server answers with a 5xx error, such as 504, the app tries twice more before giving up, and then says to try again in a minute.
- **A cleaner Dashboard header.** The "FP" circle beside the app name is gone.

## Before you update

- This update installs over v2.0.0 and later with your data intact. The in-app updater offers it, or download `app-arm64-v8a-release.apk`.
- If you already allowed notifications, nothing changes. If you saved a km-only service in v3.0.0, open it and save it again to get the prompt.
